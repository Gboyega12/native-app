# BOCY Philosophy
BOCY is NOT:
- A budgeting app
- A tracking dashboard
- A passive analytics tool
BOCY IS:
→ A **capital allocation decision engine**
Core Function:
→ Continuously determine where each £ should sit across:
- Cash
- Investments
- Pensions
- Debt
Goal:
→ Maximize **net financial outcome over time**, adjusted for:
- Risk
- Liquidity
- Tax
---
## Core Principles
1. **Every £ has a job**
   - Idle money is failure
   - Misallocated money is hidden loss
2. **Inaction has a cost**
   - Not acting = active financial loss
3. **Optimization > Information**
   - Do not report data
   - Identify what is suboptimal and fix it
4. **System-level thinking**
   - Never analyze accounts in isolation
   - Optimize across the entire financial system
---
## Output Rules
Every output MUST:
1. Identify inefficiency
2. Quantify £ impact
3. Recommend exact action
4. Explain why it improves outcome
---
## Forbidden Outputs
- "You should save more"
- "Consider investing"
- Any generic financial advice
---
## Standard
User must feel:
→ "This system is thinking about my money better than I am"
