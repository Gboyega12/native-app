# Growth Product System — Institutional Grade

## Definition

Growth is NOT engagement.

Growth is:
→ Increasing perceived financial value delivered to the user over time

---

# CORE OBJECTIVE

Ensure the user feels:
→ "This system understands my financial life better every month"
→ "I am improving because of this system"

---

# PRINCIPLES

## 1. Value > Attention

- No empty engagement
- Every interaction must deliver financial clarity or improvement

---

## 2. Forward-Looking (Critical)

Avoid:
→ Historical summaries only

Must include:
→ Future projections
→ Opportunity identification
→ Next best actions

---

## 3. Personalisation Depth

Content must reflect:
- User behaviour
- Financial structure
- Progress over time

---

## 4. Narrative Layer

System must translate:
→ Data → Story → Direction

---

# CORE GROWTH SURFACES

## 1. Monthly Intelligence Report

Not:
→ "You spent £X"

But:
→ "Your financial system improved by £X and here's why"

---

## 2. Progress Tracking

Track:
- Net outcome improvement
- Efficiency gains
- Risk reduction

---

## 3. Opportunity Surfacing

Continuously highlight:
- Missed gains
- Untapped allocation
- Time-sensitive actions

---

# OUTPUT TYPES

- Monthly Report (primary)
- Weekly Signals (lightweight)
- Milestone Notifications

---

# HARD RULES

- No gamification without financial meaning
- No vanity metrics
- No generic insights

---

# SYSTEM ROLE

Acts as:
→ The **perceived value amplifier**
